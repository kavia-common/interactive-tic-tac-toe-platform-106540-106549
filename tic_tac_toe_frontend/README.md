# Tic Tac Toe — Ocean Professional

A modern, responsive Tic Tac Toe game built with React and styled with the Ocean Professional theme (blue & amber accents).

## Features
- Play Human vs Computer (optimal AI) or Human vs Human (local)
- Clean, centered layout with score panel, controls, and instructions
- Undo, Reset Round, and New Match controls
- Accessible UI (status updates, keyboard focus styles)
- Light/Dark theme toggle

## Scripts
- `npm start` — run the app in development
- `npm test` — run tests
- `npm run build` — production build

## Structure
- `src/App.js` — app shell, game logic, and components
- `src/App.css` — Ocean Professional styles
- `src/index.css` — global styles and variables

## Notes
No external UI libraries are used; design is handcrafted with CSS for performance and clarity.
